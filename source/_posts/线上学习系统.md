## 项目概述

本项目是一款基于 uni-app + Vue3 开发的无后端线上学习平台，采用纯前端技术栈实现，无需服务器支持即可运行。项目已成功打包为 H5 版本并部署在个人博客上，可随时随地在线访问体验。

作为一个完整的在线学习系统，它涵盖了课程浏览、学习记录、收藏管理等核心功能，界面设计简洁美观，交互流畅自然。无论是在手机端还是 PC 端，都能提供良好的用户体验。

> 该项目非常适合作为前端学习练手项目，帮助开发者掌握 uni-app 跨端开发、状态管理、本地存储等核心技术点。

## 技术栈详解

### 前端框架

- **uni-app**：基于 Vue.js 的跨端框架，一套代码可发布到 iOS、Android、H5、小程序等多个平台
- **Vue3 Composition API**：使用最新的 Vue3 组合式 API，代码组织更灵活，逻辑复用更方便
- **uni-ui**：官方 UI 组件库，提供丰富的基础组件，开发效率高

### 数据存储

- **LocalStorage**：本地持久化存储，保存用户学习进度、收藏列表等数据
- **Vue 响应式状态**：利用 Vue 的响应式系统管理全局状态

### 部署方案

- **Hexo 博客**：静态网站生成器，作为项目部署载体
- **GitHub Pages**：免费的静态网站托管服务
- **Hash 路由**：使用哈希路由模式，避免部署后页面 404 问题

## 核心功能模块

### 1. 首页与课程分类

首页采用顶部导航 + 分类标签 + 课程卡片的经典布局，用户可以快速浏览各类课程。

**功能特点：**
- 支持多维度课程分类筛选
- 课程卡片展示封面、标题、讲师、价格等关键信息
- 下拉刷新获取最新课程列表
- 上拉加载更多，实现无限滚动

### 2. 课程详情页

点击课程卡片进入详情页面，展示课程的完整信息。

**功能特点：**
- 课程封面图与视频播放区域
- 课程简介、目录、讲师信息多 Tab 切换
- 课程章节目录列表，支持展开收起
- 立即学习、加入收藏、分享等操作按钮

### 3. 学习进度记录

系统会自动记录用户的学习进度，下次进入时可快速继续学习。

**功能特点：**
- 自动保存学习进度到本地存储
- 课程列表显示学习进度百分比
- 详情页展示上次学习位置
- 支持手动标记已完成章节

### 4. 收藏与课程管理

用户可以收藏感兴趣的课程，方便后续学习。

**功能特点：**
- 一键收藏/取消收藏课程
- 收藏列表集中管理
- 支持按时间、分类排序
- 本地存储，数据永不丢失

### 5. 个人中心

个人中心页面展示用户信息和各种功能入口。

**功能特点：**
- 用户头像、昵称展示
- 学习数据统计（已学课程、学习时长等）
- 我的收藏、浏览历史入口
- 设置、关于等辅助功能

## 项目亮点

### 技术亮点

1. **纯前端实现**：无需后端接口，所有数据通过本地 Mock 数据模拟，降低开发和部署成本
2. **跨端适配**：基于 uni-app 开发，一套代码可适配 H5、小程序、App 等多个平台
3. **Hash 路由模式**：完美解决静态托管下的页面刷新 404 问题
4. **响应式布局**：自适应不同屏幕尺寸，移动端和 PC 端均有良好表现
5. **组件化开发**：页面拆分为多个可复用组件，代码结构清晰，维护性强

### 设计亮点

1. **简洁大气的 UI**：采用现代化设计风格，配色舒适，视觉层次分明
2. **流畅的交互动画**：页面切换、列表滚动、按钮点击均有过渡动画
3. **清晰的信息层级**：重要信息突出展示，次要信息合理收纳
4. **友好的空状态**：无数据时展示精美空状态插画和引导文案

### 部署亮点

1. **零成本部署**：静态文件可直接托管在 GitHub Pages、Vercel 等免费平台
2. **快速加载**：纯静态页面，首屏加载速度快
3. **易于维护**：修改内容只需重新打包部署，无需服务器运维
4. **安全稳定**：纯静态网站，无后端漏洞风险

## 部署到 Hexo 博客详细教程

### 第一步：配置 uni-app 项目

打开项目根目录下的 `manifest.json` 文件，切换到**源码视图**，在文件末尾添加 H5 配置节点：

```json
"h5" : {
    "publicPath": "/demos/study-system/",
    "router": {
        "mode": "hash"
    },
    "title": "线上学习系统",
    "optimization": {
        "treeShaking": {
            "enable": true
        }
    }
}
```

**配置说明：**
- `publicPath`：静态资源路径前缀，必须与部署目录一致
- `router.mode`：路由模式，必须使用 `hash` 才能在静态托管下正常工作
- `title`：网页标题
- `optimization`：开启 treeShaking 优化打包体积

### 第二步：打包 H5 静态文件

在 HBuilderX 中执行以下操作：

1. 点击顶部菜单：**发行** → **网站 - H5 手机版**
2. 在弹出的配置框中确认网站标题和域名
3. 点击**发行**按钮开始打包

打包完成后，生成的静态文件位于：

```plaintext
/unpackage/dist/build/h5/
```

### 第三步：复制到 Hexo 博客目录

进入 Hexo 博客项目，在 `source/demos/` 目录下新建文件夹 `study-system`（文件夹名需与 publicPath 配置一致）。

将打包好的 `h5` 文件夹内的**所有文件**复制到 `source/demos/study-system/` 目录下。

最终目录结构：

```
blog/
└── source/
    └── demos/
        └── study-system/
            ├── index.html
            ├── static/
            └── ...
```

### 第四步：执行 Hexo 部署命令

打开终端，进入 Hexo 博客根目录，依次执行以下命令：

```bash
# 清理缓存
hexo clean

# 生成静态文件
hexo generate

# 部署到远程服务器
hexo deploy
```

也可以使用简化的一键命令：

```bash
hexo clean && hexo g && hexo d
```

### 第五步：在线访问验证

部署完成后，等待几分钟即可通过以下地址访问项目：

```plaintext
https://xumin8888.github.io/demos/study-system/
```

## 常见问题排查指南

### 问题一：页面空白、样式丢失

**可能原因：**
- 未配置 `publicPath` 或配置错误
- 静态资源路径不正确

**解决方案：**
1. 检查 `manifest.json` 中的 `publicPath` 配置
2. 确保路径格式为 `/demos/study-system/`（前后都有斜杠）
3. 重新打包并覆盖部署文件

### 问题二：图片等资源 404 报错

**可能原因：**
- publicPath 配置与实际部署路径不一致
- 资源文件未正确复制

**解决方案：**
1. 确认 publicPath 与部署目录完全匹配
2. 检查 `static` 目录下的资源文件是否完整
3. 不要使用 `./` 相对路径，必须使用绝对路径前缀

### 问题三：页面跳转后刷新 404

**可能原因：**
- 使用了 history 路由模式
- 静态托管服务器不支持 history 模式

**解决方案：**
1. 将路由模式改为 `hash` 模式
2. 重新打包部署
3. 确认 URL 中包含 `#` 符号

### 问题四：手机端显示不正常

**可能原因：**
- viewport 配置问题
- 样式适配问题

**解决方案：**
1. 检查 `index.html` 中的 viewport meta 标签
2. 使用 rpx 单位进行适配
3. 避免使用固定像素值
