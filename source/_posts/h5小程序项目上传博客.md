一、核心前提  
Hexo 博客可正常部署（hexo g /hexo d 可用）  
uni-app 项目本地可运行，无后端接口依赖  
二、单个项目完整部署步骤

1. uni-app 配置（必做，解决空白 / 样式丢失）  
   打开项目 manifest.json → 源码视图，末尾追加 h5 配置：

|  |  |
| --- | --- |
| ``` 1 2 3 4 5 6 ``` | ``` "h5": {     "publicPath": "./",     "router": {         "mode": "hash"     } } ``` |

2. 打包 H5 静态文件  
   HBuilderX 顶部：发行 → 网站 - H5 手机版 → 发行打包完成目录：  
   plaintext  
   项目/unpackage/dist/build/h5/
3. Hexo 博客新建目录  
   进入博客：source/demos/新建英文文件夹，例如：uni-sell
4. 复制打包文件  
   复制 h5 文件夹内所有内容粘贴到：source/demos/uni-sell/
5. 执行 Hexo 部署命令（博客根目录运行）

|  |  |
| --- | --- |
| ``` 1 2 3 4 ``` | ``` 运行 hexo clean hexo g hexo d ``` |

三合一简化命令：

|  |  |
| --- | --- |
| ``` 1 2 ``` | ``` 运行 hexo clean && hexo g && hexo d ``` |

6. 在线访问验证  
   访问地址格式：

|  |  |
| --- | --- |
| ``` 1 ``` | ``` https://xumin8888.github.io/demos/uni-sell/ ``` |

三、N 个项目重复部署流程（通用）  
配置 uni-app 的 manifest.json → h5 节点  
发行打包 H5  
在 source/demos/ 新建英文目录  
复制 h5 打包内容进去  
执行部署命令：

|  |  |
| --- | --- |
| ``` 1 ``` | ``` hexo clean && hexo g && hexo d ``` |

打开线上地址验证  
四、必看避坑指南（关键）  
不能双击 index.html 打开，本地空白是正常现象  
目录名必须英文、无中文、无空格、无特殊符号  
必须配置 publicPath: “./“ 和 hash 路由  
只复制 h5 内文件，不要复制 h5 文件夹本身  
页面异常优先：重新打包 → 重新覆盖 → 重新部署  
样式 / 资源丢失 → 99% 是路径配置错误，检查 manifest.json  
五、常见问题快速排查  
页面空白  
→ 未配置 h5 节点 / 路由不是 hash  
样式乱、图标不显示  
→ publicPath 不是 ./  
跳转 404  
→ 路由模式改成 hash  
访问不到项目  
→ 目录放错位置 / 未执行部署命令
