## 项目概述

本项目是一款基于 Vue3 + Element Plus 构建的外卖后台管理系统，专为餐饮企业打造的一站式运营管理平台。系统涵盖了订单管理、商品管理、店铺管理、用户管理、数据统计等核心功能模块，帮助商家高效管理日常运营。

作为一个完整的中后台管理系统项目，它采用现代化的前端技术栈，界面设计简洁大气，交互流畅自然，功能完善且实用。无论是学习 Vue3 中后台开发，还是作为实际项目的基础框架，都具有很高的参考价值。

> 该项目非常适合前端开发者学习中后台系统开发，掌握 Vue3、Element Plus、状态管理、权限控制等核心技术。

## 技术栈详解

### 前端框架

- **Vue 3**：最新的 Vue 框架版本，Composition API 更灵活，性能更优
- **Vite**：新一代前端构建工具，启动速度快，热更新即时
- **Vue Router 4**：官方路由管理器，实现页面间的导航
- **Pinia**：Vue 官方推荐的状态管理库，替代 Vuex，API 更简洁
- **Element Plus**：基于 Vue3 的企业级 UI 组件库，组件丰富，文档完善

### 样式与工具

- **SCSS/Sass**：CSS 预处理器，支持变量、嵌套、混合等特性
- **CSS 变量**：主题定制，支持明暗主题切换
- **ECharts**：数据可视化图表库，展示各类统计数据
- **Axios**：HTTP 请求库，统一封装接口请求
- **dayjs**：轻量级日期处理库

### 工程化

- **ESLint**：代码规范检查
- **Prettier**：代码格式化
- **Husky + lint-staged**：Git 提交代码检查
- **模块化架构**：清晰的目录结构和模块划分

## 核心功能实现

### 权限控制实现

系统采用路由 + 角色的权限控制方案：

```javascript
// store/modules/permission.js
import { defineStore } from 'pinia'
import { asyncRoutes, constantRoutes } from '@/router'

function hasPermission(roles, route) {
  if (route.meta && route.meta.roles) {
    return roles.some(role => route.meta.roles.includes(role))
  }
  return true
}

function filterAsyncRoutes(routes, roles) {
  const res = []
  routes.forEach(route => {
    const tmp = { ...route }
    if (hasPermission(roles, tmp)) {
      if (tmp.children) {
        tmp.children = filterAsyncRoutes(tmp.children, roles)
      }
      res.push(tmp)
    }
  })
  return res
}

export const usePermissionStore = defineStore('permission', {
  state: () => ({
    routes: [],
    addRoutes: []
  }),
  actions: {
    generateRoutes(roles) {
      let accessedRoutes
      if (roles.includes('admin')) {
        accessedRoutes = asyncRoutes || []
      } else {
        accessedRoutes = filterAsyncRoutes(asyncRoutes, roles)
      }
      this.addRoutes = accessedRoutes
      this.routes = constantRoutes.concat(accessedRoutes)
      return accessedRoutes
    }
  }
})
```

### Axios 请求封装

统一的 HTTP 请求封装，处理通用逻辑：

```javascript
// utils/request.js
import axios from 'axios'
import { ElMessage, ElMessageBox } from 'element-plus'
import { useUserStore } from '@/store/modules/user'

const service = axios.create({
  baseURL: import.meta.env.VITE_APP_BASE_API,
  timeout: 15000
})

// 请求拦截器
service.interceptors.request.use(
  config => {
    const userStore = useUserStore()
    if (userStore.token) {
      config.headers['Authorization'] = 'Bearer ' + userStore.token
    }
    return config
  },
  error => {
    return Promise.reject(error)
  }
)

// 响应拦截器
service.interceptors.response.use(
  response => {
    const res = response.data
    if (res.code !== 200) {
      ElMessage({
        message: res.message || 'Error',
        type: 'error',
        duration: 5 * 1000
      })
      if (res.code === 401) {
        ElMessageBox.confirm('登录状态已过期', '提示', {
          confirmButtonText: '重新登录',
          type: 'warning'
        }).then(() => {
          const userStore = useUserStore()
          userStore.resetToken()
          location.reload()
        })
      }
      return Promise.reject(new Error(res.message || 'Error'))
    } else {
      return res
    }
  },
  error => {
    ElMessage({
      message: error.message,
      type: 'error',
      duration: 5 * 1000
    })
    return Promise.reject(error)
  }
)

export default service
```

### 表格组件封装

对 Element Plus 表格进行二次封装，简化使用：

```vue
<!-- components/ProTable/index.vue -->
<template>
  <div class="pro-table">
    <el-table
      v-loading="loading"
      :data="tableData"
      :columns="columns"
      @selection-change="handleSelectionChange"
    >
      <template v-for="col in columns" :key="col.prop" v-slot:[`${col.prop}`]="{ row }">
        <slot :name="col.prop" :row="row"></slot>
      </template>
    </el-table>
    <el-pagination
      v-if="showPagination"
      class="pagination"
      :total="total"
      v-model:current-page="pageNum"
      v-model:page-size="pageSize"
      @size-change="handleSizeChange"
      @current-change="handleCurrentChange"
    />
  </div>
</template>

<script setup>
import { ref, watch } from 'vue'

const props = defineProps({
  columns: { type: Array, required: true },
  data: { type: Array, default: () => [] },
  loading: { type: Boolean, default: false },
  total: { type: Number, default: 0 },
  showPagination: { type: Boolean, default: true }
})

const emit = defineEmits(['selection-change', 'page-change'])

const tableData = ref([])
const pageNum = ref(1)
const pageSize = ref(10)

watch(() => props.data, (val) => {
  tableData.value = val
}, { immediate: true, deep: true })

function handleSelectionChange(selection) {
  emit('selection-change', selection)
}

function handleSizeChange(size) {
  pageSize.value = size
  emit('page-change', { pageNum: pageNum.value, pageSize: size })
}

function handleCurrentChange(page) {
  pageNum.value = page
  emit('page-change', { pageNum: page, pageSize: pageSize.value })
}
</script>
```

## 开发规范

### 命名规范

- **组件名**：大驼峰命名，如 `UserList.vue`
- **文件名**：页面和组件使用大驼峰，工具函数使用小驼峰
- **变量名**：小驼峰命名，语义化
- **常量名**：全大写下划线分隔，如 `MAX_COUNT`

### 目录规范

- 页面组件放在 `views/` 目录
- 公共组件放在 `components/` 目录
- 接口请求放在 `api/` 目录
- 工具函数放在 `utils/` 目录
- 静态资源放在 `assets/` 目录

### Git 提交规范

- `feat`：新功能
- `fix`：修复 bug
- `docs`：文档更新
- `style`：代码格式调整
- `refactor`：代码重构
- `perf`：性能优化
- `test`：测试相关
- `chore`：构建/工具相关
