## 项目简介

这是一个基于 uni-app 开发的无后端点餐小程序，已打包为 H5 并部署到博客。

## 技术栈

* 前端框架：uni-app（Vue3）
* UI 组件：uni-ui
* 部署方式：Hexo 博客 + GitHub Pages

## 功能演示

[点击在线体验](/demos/sellH5-project/)

## 核心功能

1. 商品分类浏览
2. 购物车管理
3. 订单提交与模拟支付
4. 本地存储记录购物车数据

## 项目亮点

* 纯前端实现，无后端依赖，直接部署静态文件即可运行
* 适配移动端布局，在手机端访问体验更佳
* 使用 `hash` 路由模式，避免部署后 404 问题

## 项目部署步骤

### 1. 配置 uni-app 项目（必做）

打开 `manifest.json` → 切换到**源码视图**，在文件末尾添加 H5 配置：

```
"h5" : {
    "publicPath": "/demos/sellH5-project/",
    "router": {
        "mode": "hash"
    }
}
2. 打包 H5 静态文件
在 HBuilderX 中执行：发行 → 网站 - H5 手机版 → 发行
打包完成后，文件输出目录：
plaintext
/unpackage/dist/build/h5/
3. 放入 Hexo 博客静态目录
进入 Hexo 博客项目
在 source/demos/ 下新建文件夹：sellH5-project
将 h5 文件夹内所有文件复制到 source/demos/sellH5-project/
4. 执行 Hexo 部署命令
打开终端，进入 Hexo 根目录，执行：
bash
运行
hexo clean
hexo generate
hexo deploy
一键简化命令：
bash
运行
hexo clean && hexo g && hexo d
5. 在线访问项目
部署完成后，即可通过链接访问：
plaintext
https://xumin8888.github.io/demos/sellH5-project/
常见问题排查
页面空白、样式丢失
未配置 publicPath 或路径错误
重新配置 → 重新打包 → 覆盖文件 → 重新部署
资源 404 报错
publicPath 必须写 /demos/sellH5-project/
不能使用 ./
页面跳转 404
路由必须使用 hash 模式
总结
本项目采用 uni-app 纯前端实现，无需后端服务器，直接打包为 H5 静态网站部署到 Hexo 博客，可随时随地在线预览、展示个人项目作品。
```
