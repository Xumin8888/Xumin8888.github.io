## 项目概述

本项目是一个完整的微信小程序电商平台，采用 uni-app 跨端框架开发，一套代码可同时发布到微信小程序、支付宝小程序、H5、App 等多个平台。项目涵盖了商品浏览、购物车、订单管理、支付、用户中心等完整电商功能，是学习小程序开发的绝佳实战项目。

作为移动端电商解决方案，它遵循小程序设计规范，注重用户体验和性能优化，所有交互和动画都经过精心打磨。无论是学习小程序开发，还是作为实际项目的基础框架，都具有很高的参考价值。

> 该项目是学习小程序电商开发的完整实战教程，涵盖了从小程序基础到复杂业务实现的全流程。

## 技术栈详解

### 开发框架

- **uni-app**：基于 Vue.js 的跨端框架，一套代码多端运行
- **Vue 3**：使用 Vue3 Composition API，更灵活的代码组织方式
- **Vuex / Pinia**：状态管理，管理全局状态
- **Vue Router**：页面路由管理

### UI 组件库

- **uni-ui**：DCloud 官方 UI 组件库，跨端兼容好
- **uView UI**：功能强大的 uni-app 生态 UI 库
- **自定义组件**：业务相关的自定义组件封装

### 工具库

- **uView**：全面的组件和工具函数库
- **uni-request**：Promise 化的请求库
- **dayjs**：轻量级日期处理库
- **Lodash**：工具函数库

### 开发工具

- **HBuilderX**：官方推荐的 uni-app 开发 IDE
- **微信开发者工具**：微信小程序调试工具
- **VS Code**：代码编辑（可选）

## 核心功能实现

### 请求封装

```javascript
// utils/request.js
const BASE_URL = 'https://api.example.com'

function request(options) {
  return new Promise((resolve, reject) => {
    const token = uni.getStorageSync('token')
    
    uni.request({
      url: BASE_URL + options.url,
      method: options.method || 'GET',
      data: options.data || {},
      header: {
        'Content-Type': 'application/json',
        'Authorization': token ? `Bearer ${token}` : ''
      },
      success: res => {
        const data = res.data
        
        if (data.code === 200) {
          resolve(data)
        } else if (data.code === 401) {
          uni.showToast({ title: '请先登录', icon: 'none' })
          uni.navigateTo({ url: '/pages/user/login/login' })
          reject(data)
        } else {
          uni.showToast({
            title: data.message || '请求失败',
            icon: 'none'
          })
          reject(data)
        }
      },
      fail: err => {
        uni.showToast({
          title: '网络请求失败',
          icon: 'none'
        })
        reject(err)
      }
    })
  })
}

export default {
  get(url, data) {
    return request({ url, method: 'GET', data })
  },
  post(url, data) {
    return request({ url, method: 'POST', data })
  },
  put(url, data) {
    return request({ url, method: 'PUT', data })
  },
  delete(url, data) {
    return request({ url, method: 'DELETE', data })
  }
}
```

### 购物车状态管理（Vuex）

```javascript
// store/modules/cart.js
import api from '@/api/cart'

const state = {
  cartList: [],
  selectedIds: []
}

const getters = {
  totalCount: state => {
    return state.cartList.reduce((sum, item) => sum + item.count, 0)
  },
  totalPrice: state => {
    return state.cartList
      .filter(item => state.selectedIds.includes(item.id))
      .reduce((sum, item) => sum + item.price * item.count, 0)
      .toFixed(2)
  },
  selectedCount: state => state.selectedIds.length,
  isAllSelected: state => {
    return state.cartList.length > 0 && 
           state.selectedIds.length === state.cartList.length
  }
}

const mutations = {
  SET_CART_LIST(state, list) {
    state.cartList = list
  },
  TOGGLE_SELECT(state, id) {
    const index = state.selectedIds.indexOf(id)
    if (index > -1) {
      state.selectedIds.splice(index, 1)
    } else {
      state.selectedIds.push(id)
    }
  },
  TOGGLE_SELECT_ALL(state, selected) {
    if (selected) {
      state.selectedIds = state.cartList.map(item => item.id)
    } else {
      state.selectedIds = []
    }
  },
  UPDATE_COUNT(state, { id, count }) {
    const item = state.cartList.find(item => item.id === id)
    if (item) {
      item.count = count
    }
  }
}

const actions = {
  async getCartList({ commit }) {
    try {
      const res = await api.getCartList()
      commit('SET_CART_LIST', res.data || [])
    } catch (error) {
      console.error('获取购物车失败:', error)
    }
  },
  async addToCart({ dispatch }, goods) {
    try {
      await api.addToCart(goods)
      dispatch('getCartList')
      uni.showToast({ title: '已加入购物车', icon: 'success' })
    } catch (error) {
      console.error('加入购物车失败:', error)
    }
  },
  async updateCart({ dispatch }, { id, count }) {
    try {
      await api.updateCart(id, { count })
      dispatch('getCartList')
    } catch (error) {
      console.error('更新购物车失败:', error)
    }
  },
  async deleteFromCart({ dispatch }, id) {
    try {
      await api.deleteCart(id)
      dispatch('getCartList')
    } catch (error) {
      console.error('删除购物车失败:', error)
    }
  }
}

export default {
  namespaced: true,
  state,
  getters,
  mutations,
  actions
}
```

### 列表页分页加载

```vue
<!-- 列表页分页示例 -->
<template>
  <view class="product-list">
    <scroll-view
      scroll-y
      refresher-enabled
      :refresher-triggered="refreshing"
      @refresherrefresh="onRefresh"
      @scrolltolower="onLoadMore"
    >
      <view class="list-content">
        <ProductCard
          v-for="item in productList"
          :key="item.id"
          :product="item"
        />
      </view>
      
      <LoadMore :status="loadMoreStatus" />
    </scroll-view>
  </view>
</template>

<script setup>
import { ref, onMounted } from 'vue'
import ProductCard from '@/components/common/ProductCard/index.vue'
import LoadMore from '@/components/common/LoadMore/index.vue'
import api from '@/api/product'

const productList = ref([])
const pageNum = ref(1)
const pageSize = ref(10)
const total = ref(0)
const refreshing = ref(false)
const loadMoreStatus = ref('loadmore') // loadmore | loading | nomore

async function getList() {
  try {
    const res = await api.getProductList({
      pageNum: pageNum.value,
      pageSize: pageSize.value
    })
    total.value = res.total
    if (pageNum.value === 1) {
      productList.value = res.list || []
    } else {
      productList.value = [...productList.value, ...(res.list || [])]
    }
    
    if (productList.value.length >= total.value) {
      loadMoreStatus.value = 'nomore'
    } else {
      loadMoreStatus.value = 'loadmore'
    }
  } catch (error) {
    console.error('获取列表失败:', error)
  }
}

function onRefresh() {
  refreshing.value = true
  pageNum.value = 1
  loadMoreStatus.value = 'loadmore'
  getList().finally(() => {
    refreshing.value = false
  })
}

function onLoadMore() {
  if (loadMoreStatus.value !== 'loadmore') return
  loadMoreStatus.value = 'loading'
  pageNum.value++
  getList()
}

onMounted(() => {
  getList()
})
</script>
```

## 性能优化建议

### 1. 分包加载

将非核心页面放在分包中，减少主包体积。

```json
// pages.json
{
  "pages": [
    { "path": "pages/index/index" },
    { "path": "pages/category/index" },
    { "path": "pages/cart/index" },
    { "path": "pages/mine/index" }
  ],
  "subPackages": [
    {
      "root": "pages/product",
      "pages": [
        { "path": "detail" },
        { "path": "list" }
      ]
    },
    {
      "root": "pages/order",
      "pages": [
        { "path": "list" },
        { "path": "detail" },
        { "path": "confirm" }
      ]
    }
  ]
}
```

### 2. 图片优化

- 使用 WebP 格式图片
- 图片懒加载
- 合理设置图片尺寸
- 使用 CDN 加速

### 3. 列表优化

- 使用虚拟滚动（大数据量时）
- 合理使用 `onReachBottom` 分页加载
- 避免在列表项中使用复杂计算

### 4. 其他优化

- 避免频繁 setData
- 合理使用缓存
- 优化首屏加载时间
- 减少包体积

## 开发规范

### 命名规范

- **页面和组件**：使用短横线连接，如 `product-list`
- **文件名**：使用小写，单词用短横线连接
- **变量和函数**：使用小驼峰，如 `getProductList`
- **常量**：使用大写下划线，如 `PAGE_SIZE`

### 目录规范

- 页面放在 `pages/` 目录
- 公共组件放在 `components/` 目录
- 接口请求放在 `api/` 目录
- 工具函数放在 `utils/` 目录
- 静态资源放在 `static/` 目录
