## 项目概述

本项目是一款面向企业运营、数据分析、监控中心的实时数据可视化大屏平台。采用 Vue3 + ECharts 技术栈构建，涵盖数据概览、业务指标展示、多维度图表分析、实时数据刷新、全屏展示、自适应屏幕分辨率等核心功能。

作为企业级数据监控解决方案，它能够直观、高效、实时地展示业务数据，帮助管理层快速掌握业务状态、提升决策效率。项目已成功部署到个人博客，可在线访问体验。

> 该项目非常适合学习数据可视化开发，掌握 ECharts 图表库、大屏自适应、实时数据更新等核心技术。

## 技术栈详解

### 前端框架

- **Vue3**：最新的 Vue 框架版本，性能更优，Composition API 更灵活
- **Vite**：新一代前端构建工具，启动速度快，热更新即时
- **Vue-Router**：官方路由管理器，实现页面间的导航
- **Pinia**：Vue 官方推荐的状态管理库，替代 Vuex
- **Element Plus**：基于 Vue3 的组件库，提供丰富的 UI 组件

### 数据可视化

- **ECharts**：百度开源的数据可视化图表库，功能强大，图表类型丰富
- **ECharts GL**：3D 可视化扩展，支持地球、3D 柱状图等高级图表
- **数据地图**：基于 GeoJSON 的地图数据可视化

### 数据交互

- **Axios**：HTTP 请求库，用于获取后端接口数据
- **WebSocket**：实时数据推送协议，实现数据实时更新
- **定时器轮询**：定时请求最新数据，保证数据时效性

### 部署方案

- **Hexo 博客**：静态网站生成器，作为项目部署载体
- **GitHub Pages**：免费的静态网站托管服务

### 5. 底部辅助功能

## 核心技术实现

### ECharts 图表封装

将 ECharts 封装为 Vue 组件，方便复用：

```javascript
// components/charts/LineChart.vue
import * as echarts from 'echarts'
import { onMounted, onUnmounted, ref, watch } from 'vue'

const chartRef = ref(null)
let chartInstance = null

function initChart() {
  chartInstance = echarts.init(chartRef.value)
  updateChart()
}

function updateChart() {
  const option = {
    // 图表配置
    tooltip: { trigger: 'axis' },
    xAxis: { type: 'category', data: props.xData },
    yAxis: { type: 'value' },
    series: [{ type: 'line', data: props.yData, smooth: true }]
  }
  chartInstance.setOption(option)
}

function handleResize() {
  chartInstance?.resize()
}

onMounted(() => {
  initChart()
  window.addEventListener('resize', handleResize)
})

onUnmounted(() => {
  window.removeEventListener('resize', handleResize)
  chartInstance?.dispose()
})

watch(() => props.data, () => {
  updateChart()
}, { deep: true })
```

### 大屏自适应方案

使用 scale 方案实现大屏等比缩放适配：

```javascript
// utils/resize.js
export function useResize(designWidth = 1920, designHeight = 1080) {
  function resize() {
    const scaleX = window.innerWidth / designWidth
    const scaleY = window.innerHeight / designHeight
    const scale = Math.min(scaleX, scaleY)
    
    document.getElementById('dashboard').style.transform = 
      `translate(-50%, -50%) scale(${scale})`
  }
  
  onMounted(() => {
    resize()
    window.addEventListener('resize', resize)
  })
  
  onUnmounted(() => {
    window.removeEventListener('resize', resize)
  })
}
```

### 实时数据更新

通过定时器轮询实现数据定时刷新：

```javascript
// store/dashboard.js
import { defineStore } from 'pinia'
import { ref } from 'vue'
import { fetchDashboardData } from '@/api'

export const useDashboardStore = defineStore('dashboard', () => {
  const data = ref({})
  let timer = null

  async function loadData() {
    try {
      const res = await fetchDashboardData()
      data.value = res.data
    } catch (error) {
      console.error('数据加载失败:', error)
    }
  }

  function startRefresh(interval = 5000) {
    stopRefresh()
    timer = setInterval(loadData, interval)
  }

  function stopRefresh() {
    if (timer) {
      clearInterval(timer)
      timer = null
    }
  }

  return { data, loadData, startRefresh, stopRefresh }
})
```

```javascript
// 监听窗口大小变化，自动调整图表
```

```javascript
chart.setOption(newOption, {

  lazyUpdate: true,
  silent: false
```

### 4. 图表联动

```javascript
// 多个图表联动
```

## 性能优化建议

1. **图表懒加载**：不可见区域的图表延迟初始化
2. **数据节流**：高频数据更新时使用节流函数
3. **减少重绘**：尽量使用 setOption 更新数据，而非重新初始化
4. **合理采样**：大量数据点时进行降采样处理
5. **WebGL 渲染**：大数据量图表使用 ECharts GL 的 WebGL 渲染
6. **资源预加载**：关键资源提前预加载，提升首屏速度
