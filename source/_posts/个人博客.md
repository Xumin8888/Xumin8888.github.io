## 前言

在当今互联网时代，拥有一个属于自己的个人博客不仅是技术能力的展示，更是知识沉淀与个人品牌建设的重要载体。Hexo 作为一款基于 Node.js 的静态博客框架，以其高效的生成速度、丰富的主题生态和简洁的配置方式，成为众多开发者搭建个人博客的首选。

本文将从零开始，带你一步步完成 Hexo 博客的完整搭建流程，涵盖环境准备、博客初始化、主题选择、基础配置到最终部署上线的全过程。无论你是编程新手还是有一定经验的开发者，都能通过本文顺利搭建出属于自己的精美博客。

## 一、前期准备：环境搭建

在开始搭建 Hexo 博客之前，我们需要先准备好必要的开发环境。Hexo 依赖于 Git 和 Node.js，因此这两个工具是必不可少的。

### 1.1 Git 安装与配置

Git 是目前最流行的分布式版本控制系统，也是我们将博客部署到 GitHub Pages 的必备工具。

#### 下载与安装

访问 Git 国内镜像站下载安装包：

- 淘宝镜像：<https://npm.taobao.org/mirrors/git-for-windows/>
- 官方网站：<https://git-scm.com/downloads>

选择最新版本的 64 位安装包（`.exe` 文件），下载完成后双击运行。

**安装注意事项：**
- 安装路径建议选择非系统盘（如 `D:\Program Files\Git`）
- 组件选择保持默认即可
- 编辑器选择推荐使用 VS Code（如已安装）
- 环境变量选择「Git from the command line and also from 3rd-party software」
- 其余选项保持默认，一路 Next 完成安装

#### 验证安装

安装完成后，打开「命令提示符（CMD）」或「PowerShell」，输入以下命令验证：

```bash
git --version
```

如果输出版本号信息（如 `git version 2.x.x`），说明安装成功。

### 1.2 Node.js 安装

Hexo 基于 Node.js 运行，因此需要先安装 Node.js 环境。推荐安装 LTS（长期支持）版本，稳定性更好。

#### 下载与安装

访问 Node.js 官网：<https://nodejs.org/>

下载 LTS 版本（左侧绿色按钮），双击安装包进行安装。

**安装注意事项：**
- 勾选「Add to PATH」（非常重要，否则命令行无法识别 node 命令）
- 安装路径建议选择非系统盘
- 其余选项保持默认即可

#### 验证安装

打开新的命令提示符窗口，依次执行：

```bash
node -v
npm -v
```

如果两个命令都输出版本号，说明 Node.js 安装成功。

### 1.3 npm 镜像源配置（国内加速）

由于国内网络环境原因，直接使用官方 npm 源速度较慢，建议配置国内镜像源：

```bash
npm config set registry https://registry.npmmirror.com
```

验证配置是否生效：

```bash
npm config get registry
```

输出 `https://registry.npmmirror.com` 即为配置成功。

### 1.4 GitHub 账号注册与 SSH 配置

GitHub Pages 是我们托管博客的免费平台，需要先注册 GitHub 账号并配置 SSH 密钥。

#### 注册 GitHub 账号

访问 GitHub 官网：<https://github.com/>

点击右上角「Sign up」，按照提示完成注册。建议使用常用邮箱注册，方便后续接收通知。

#### 生成 SSH 密钥

配置 SSH 密钥可以实现免密推送代码，避免每次部署都输入用户名和密码。

打开 Git Bash（右键桌面选择「Git Bash Here」），执行以下命令（**将邮箱替换为你注册 GitHub 时使用的邮箱**）：

```bash
ssh-keygen -t rsa -b 4096 -C "your_email@example.com"
```

执行后会有三次提示：
- 第一次：询问密钥保存位置，直接回车使用默认路径
- 第二次：询问密码，直接回车（不设置密码）
- 第三次：确认密码，直接回车

生成完成后，密钥文件保存在 `C:\Users\你的用户名\.ssh\` 目录下，包含两个文件：
- `id_rsa`：私钥文件，**切勿泄露给他人**
- `id_rsa.pub`：公钥文件，需要添加到 GitHub

#### 添加公钥到 GitHub

1. 用记事本打开 `id_rsa.pub` 文件，复制全部内容
2. 打开 GitHub SSH 设置页面：<https://github.com/settings/keys>
3. 点击「New SSH key」
4. Title 随便填（如 `My-PC`），Key 粘贴刚才复制的公钥内容
5. 点击「Add SSH key」完成添加

#### 测试 SSH 连接

在 Git Bash 中执行：

```bash
ssh -T git@github.com
```

如果提示 `Are you sure you want to continue connecting (yes/no/[fingerprint])?`，输入 `yes` 回车。

出现类似 `Hi 你的用户名! You've successfully authenticated...` 的提示，说明 SSH 配置成功！

## 二、Hexo 博客初始化

环境准备就绪后，我们来正式初始化 Hexo 博客。

### 2.1 安装 Hexo 命令行工具

全局安装 Hexo CLI：

```bash
npm install -g hexo-cli
```

安装完成后，验证是否安装成功：

```bash
hexo -v
```

输出版本号信息即为安装成功。

### 2.2 初始化博客项目

选择一个合适的位置创建博客文件夹（建议路径不要包含中文和空格），例如 `D:\blog`。

在命令行中进入目标目录，执行初始化命令：

```bash
hexo init myblog
cd myblog
npm install
```

命令解释：
- `hexo init myblog`：在当前目录下创建 `myblog` 文件夹并初始化 Hexo 博客
- `cd myblog`：进入博客目录
- `npm install`：安装博客所需的依赖包

安装完成后，你的博客目录结构大致如下：

```
myblog/
├── node_modules/      # 依赖包目录
├── scaffolds/         # 文章模板目录
├── source/            # 资源目录（文章、页面等）
│   └── _posts/        # 博客文章存放目录
├── themes/            # 主题目录
├── _config.yml        # 博客主配置文件
└── package.json       # 项目配置文件
```

### 2.3 本地预览博客

初始化完成后，我们可以先在本地预览一下博客效果：

```bash
hexo clean
hexo generate
hexo server
```

简写方式：

```bash
hexo clean && hexo g && hexo s
```

命令解释：
- `hexo clean`：清理缓存文件和已生成的静态文件
- `hexo generate`（简写 `hexo g`）：生成静态文件
- `hexo server`（简写 `hexo s`）：启动本地服务器

启动成功后，在浏览器中访问 `http://localhost:4000`，就可以看到你的博客了！

按 `Ctrl + C` 可以停止本地服务器。

## 三、Butterfly 主题安装与基础配置

Hexo 默认的主题比较简洁，这里推荐使用 Butterfly 主题——一款功能丰富、界面美观的 Hexo 主题。

### 3.1 安装 Butterfly 主题

在博客根目录下执行以下命令克隆主题：

```bash
git clone -b master https://github.com/jerryc127/hexo-theme-butterfly.git themes/butterfly
```

### 3.2 安装主题依赖

Butterfly 主题需要一些额外的渲染插件：

```bash
npm install hexo-renderer-pug hexo-renderer-stylus --save
```

### 3.3 启用主题

打开博客根目录的 `_config.yml` 文件（**注意不是主题目录里的**），找到 `theme` 配置项，修改为：

```yaml
theme: butterfly
```

保存后，重新生成并预览：

```bash
hexo clean && hexo g && hexo s
```

访问 `http://localhost:4000`，就可以看到 Butterfly 主题的效果了。

## 四、博客基础配置

接下来我们对博客进行一些基础配置，让它更符合个人风格。

### 4.1 站点信息配置

打开根目录 `_config.yml`，找到以下配置项进行修改：

```yaml
# 博客标题
title: 我的技术博客

# 博客副标题（显示在标题下方）
subtitle: 记录技术，分享生活

# 博客描述（用于 SEO）
description: 一个专注于前端开发与技术分享的个人博客

# 博主名称
author: 你的名字

# 博客语言（Butterfly 主题支持中文）
language: zh-CN

# 时区
timezone: Asia/Shanghai
```

### 4.2 网址配置

如果你使用 GitHub Pages 托管博客，配置如下：

```yaml
# 你的博客地址
url: https://你的用户名.github.io

# 根路径，GitHub Pages 默认为 /
root: /
```

### 4.3 文章格式配置

```yaml
# 文章链接格式（更友好的 URL）
permalink: :year/:month/:day/:title/

# 分页配置
per_page: 10
pagination_dir: page
```

## 五、导航栏菜单配置

Butterfly 主题的导航栏需要在主题配置文件中设置。

### 5.1 修改主题配置

打开主题配置文件 `themes/butterfly/_config.yml`，搜索 `menu`，修改为：

```yaml
menu:
  首页: / || fas fa-home
  归档: /archives/ || fas fa-archive
  分类: /categories/ || fas fa-folder-open
  标签: /tags/ || fas fa-tags
  关于我: /about/ || fas fa-user
```

菜单项格式说明：`菜单名: 路径 || 图标`

图标可以在 [Font Awesome](https://fontawesome.com/icons) 官网查找，使用 `fas fa-xxx` 格式。

### 5.2 创建分类、标签和关于页面

导航栏中配置的页面需要手动创建：

```bash
# 创建分类页面
hexo new page categories

# 创建标签页面
hexo new page tags

# 创建关于页面
hexo new page about
```

#### 配置分类页面

打开 `source/categories/index.md`，修改为：

```markdown
---
title: 分类
date: 2026-01-01 00:00:00
type: "categories"
layout: "categories"
---
```

#### 配置标签页面

打开 `source/tags/index.md`，修改为：

```markdown
---
title: 标签
date: 2026-01-01 00:00:00
type: "tags"
layout: "tags"
---
```

#### 配置关于页面

打开 `source/about/index.md`，在其中编写你的个人介绍内容即可。

## 六、部署到 GitHub Pages

博客配置完成后，我们将它部署到 GitHub Pages 上，让所有人都能访问。

### 6.1 创建 GitHub 仓库

1. 登录 GitHub，点击右上角「+」→「New repository」
2. 仓库名称必须为：`你的用户名.github.io`（**注意：必须完全一致**）
3. 选择「Public」（公开仓库）
4. 勾选「Add a README file」（可选）
5. 点击「Create repository」

> **重要**：仓库名必须是 `用户名.github.io` 格式，否则 GitHub Pages 不会正常工作。

### 6.2 安装部署插件

在博客根目录执行：

```bash
npm install hexo-deployer-git --save
```

### 6.3 配置部署信息

打开根目录 `_config.yml`，在文件底部找到 `deploy` 配置项，修改为：

```yaml
deploy:
  type: git
  repo: git@github.com:你的用户名/你的用户名.github.io.git
  branch: main
```

> 注意：如果你的仓库默认分支是 `master`，则 `branch` 改为 `master`。

### 6.4 一键部署

执行部署命令：

```bash
hexo clean && hexo g && hexo d
```

命令解释：
- `hexo clean`：清理旧的缓存和生成文件
- `hexo g`：生成最新的静态文件
- `hexo d`：部署到 GitHub

首次部署可能需要等待几分钟，GitHub Pages 才会生效。

### 6.5 验证部署结果

部署完成后：

1. 打开你的 GitHub 仓库页面，确认文件已推送成功
2. 访问 `https://你的用户名.github.io` 查看博客效果
3. 如果页面没有更新，尝试清除浏览器缓存（`Ctrl + F5` 强制刷新）

> GitHub Pages 部署通常需要 1-5 分钟生效，请耐心等待。

## 七、撰写第一篇博客文章

博客搭建好了，接下来学习如何撰写文章。

### 7.1 创建新文章

在博客根目录执行：

```bash
hexo new "文章标题"
```

例如：

```bash
hexo new "我的第一篇博客"
```

执行后，会在 `source/_posts/` 目录下生成一个 `我的第一篇博客.md` 文件。

### 7.2 文章格式说明

打开生成的 Markdown 文件，可以看到如下格式：

```markdown
---
title: 我的第一篇博客
date: 2026-07-20 12:00:00
tags:
categories:
---

这里写文章正文...
```

上方 `---` 之间的内容称为 **Front-matter**，是文章的元信息：

| 配置项 | 说明 |
|--------|------|
| `title` | 文章标题 |
| `date` | 发布日期 |
| `categories` | 文章分类，可设置多个 |
| `tags` | 文章标签，可设置多个 |
| `top_img` | 文章顶部图片 |
| `cover` | 文章封面图 |
| `abbrlink` | 文章缩写链接（可选） |

### 7.3 使用 Markdown 写作

Hexo 支持标准的 Markdown 语法，你可以使用各种 Markdown 编辑器来撰写文章，推荐使用：

- **Typora**：所见即所得的 Markdown 编辑器
- **VS Code**：配合 Markdown 插件使用
- **Obsidian**：功能强大的笔记软件

### 7.4 常用 Markdown 语法

```markdown
# 一级标题
## 二级标题
### 三级标题

**加粗文字**
*斜体文字*
~~删除线~~

- 无序列表项1
- 无序列表项2

1. 有序列表项1
2. 有序列表项2

> 引用文本

`行内代码`

```代码块
代码内容
```

[链接文字](链接地址)
![图片描述](图片地址)
```

## 九、常见问题与注意事项

### 9.1 部署后页面不更新

**可能原因及解决方法：**

1. **浏览器缓存问题**：使用 `Ctrl + F5` 强制刷新，或使用无痕模式访问
2. **GitHub Pages 延迟**：等待 1-5 分钟后再刷新
3. **未执行 `hexo clean`**：部署前务必先清理缓存
4. **仓库名错误**：确保仓库名是 `用户名.github.io`

### 9.2 本地预览正常，部署后样式错乱

**可能原因：**
- `_config.yml` 中的 `url` 和 `root` 配置不正确
- 主题配置文件中的路径配置有误

**解决方法：** 检查并修正 `url` 和 `root` 配置，然后重新部署。

### 9.3 图片显示不出来

**解决方法：**
1. 将图片放在 `source/img/` 目录下
2. 在文章中使用 `/img/图片名.jpg` 的路径引用
3. 确保文件名和路径正确（区分大小写）

### 9.4 执行 hexo 命令报错

**常见原因：**
- 没有在博客根目录执行命令
- Node.js 版本过低（建议 14.x 以上）
- 依赖包安装不完整

**解决方法：**
1. 确保当前目录是博客根目录
2. 重新安装依赖：`rm -rf node_modules && npm install`
3. 更新 Node.js 到 LTS 版本
