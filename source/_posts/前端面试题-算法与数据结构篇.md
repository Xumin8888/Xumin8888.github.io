## 前言

算法与数据结构是前端面试中的重要组成部分，虽然前端岗位不像后端那样对算法要求很高，但掌握基础算法和数据结构依然是必备技能。本文整理了前端面试中高频的算法和数据结构题目，涵盖数组、字符串、链表、树、排序、查找等多个方面。

对于前端开发者来说，学习算法不仅是为了面试，更能提升逻辑思维能力和代码质量。建议大家在理解原理的基础上多动手练习，形成自己的解题思路。

## 一、复杂度分析

### 1. 时间复杂度

时间复杂度用来衡量算法运行时间随数据规模增长的变化趋势。

**常见时间复杂度（从快到慢）：**

| 复杂度 | 名称 | 示例 |
|--------|------|------|
| O(1) | 常数阶 | 直接访问数组元素 |
| O(log n) | 对数阶 | 二分查找 |
| O(n) | 线性阶 | 遍历数组 |
| O(n log n) | 线性对数阶 | 快速排序、归并排序 |
| O(n²) | 平方阶 | 冒泡排序、双重循环 |
| O(n³) | 立方阶 | 三重循环 |
| O(2ⁿ) | 指数阶 | 斐波那契递归 |
| O(n!) | 阶乘阶 | 全排列 |

**计算规则：**
- 只看最高阶项，忽略常数和低阶项
- 加法法则：总复杂度 = 各部分复杂度的最大值
- 乘法法则：嵌套循环 = 内外复杂度相乘

### 2. 空间复杂度

空间复杂度用来衡量算法运行时占用的额外存储空间。

**常见空间复杂度：**
- O(1)：只需要常数级别的额外空间
- O(n)：需要线性级别的额外空间
- O(n²)：需要平方级别的额外空间

## 二、数组

### 1. 数组去重

**题目：** 给定一个数组，去除重复元素。

**解法1：使用 Set**
```javascript
function unique(arr) {
  return [...new Set(arr)]
}
```
时间复杂度：O(n)，空间复杂度：O(n)

**解法2：使用 filter + indexOf**
```javascript
function unique(arr) {
  return arr.filter((item, index) => arr.indexOf(item) === index)
}
```
时间复杂度：O(n²)，空间复杂度：O(1)

**解法3：使用 Map**
```javascript
function unique(arr) {
  const map = new Map()
  return arr.filter(item => {
    if (!map.has(item)) {
      map.set(item, true)
      return true
    }
    return false
  })
}
```
时间复杂度：O(n)，空间复杂度：O(n)

### 2. 数组扁平化

**题目：** 将多层嵌套的数组变成一维数组。

**解法1：递归**
```javascript
function flatten(arr) {
  let result = []
  for (let i = 0; i < arr.length; i++) {
    if (Array.isArray(arr[i])) {
      result = result.concat(flatten(arr[i]))
    } else {
      result.push(arr[i])
    }
  }
  return result
}
```

**解法2：reduce + 递归**
```javascript
function flatten(arr) {
  return arr.reduce((pre, cur) => {
    return pre.concat(Array.isArray(cur) ? flatten(cur) : cur)
  }, [])
}
```

**解法3：使用 flat**
```javascript
function flatten(arr) {
  return arr.flat(Infinity)
}
```

**解法4：toString + split（只适用于数字数组）**
```javascript
function flatten(arr) {
  return arr.toString().split(',').map(Number)
}
```

### 3. 两数之和

**题目：** 给定一个整数数组 nums 和一个目标值 target，找出和为 target 的两个整数的下标。

**解法1：暴力法**
```javascript
function twoSum(nums, target) {
  for (let i = 0; i < nums.length; i++) {
    for (let j = i + 1; j < nums.length; j++) {
      if (nums[i] + nums[j] === target) {
        return [i, j]
      }
    }
  }
  return []
}
```
时间复杂度：O(n²)，空间复杂度：O(1)

**解法2：哈希表**
```javascript
function twoSum(nums, target) {
  const map = new Map()
  for (let i = 0; i < nums.length; i++) {
    const complement = target - nums[i]
    if (map.has(complement)) {
      return [map.get(complement), i]
    }
    map.set(nums[i], i)
  }
  return []
}
```
时间复杂度：O(n)，空间复杂度：O(n)

### 4. 最大子序和

**题目：** 给定一个整数数组，找出具有最大和的连续子数组，返回其最大和。

**解法：动态规划（Kadane 算法）**
```javascript
function maxSubArray(nums) {
  let maxSum = nums[0]
  let currentSum = nums[0]
  
  for (let i = 1; i < nums.length; i++) {
    currentSum = Math.max(nums[i], currentSum + nums[i])
    maxSum = Math.max(maxSum, currentSum)
  }
  
  return maxSum
}
```
时间复杂度：O(n)，空间复杂度：O(1)

### 5. 合并两个有序数组

**题目：** 给你两个有序整数数组 nums1 和 nums2，将 nums2 合并到 nums1 中，使 nums1 成为一个有序数组。

**解法：双指针（从后往前）**
```javascript
function merge(nums1, m, nums2, n) {
  let p1 = m - 1
  let p2 = n - 1
  let p = m + n - 1
  
  while (p1 >= 0 && p2 >= 0) {
    if (nums1[p1] > nums2[p2]) {
      nums1[p] = nums1[p1]
      p1--
    } else {
      nums1[p] = nums2[p2]
      p2--
    }
    p--
  }
  
  // nums2 还有剩余元素
  while (p2 >= 0) {
    nums1[p] = nums2[p2]
    p2--
    p--
  }
}
```
时间复杂度：O(m+n)，空间复杂度：O(1)

## 三、字符串

### 1. 反转字符串

**题目：** 编写一个函数，将输入的字符串反转过来。

**解法1：数组方法**
```javascript
function reverseString(s) {
  return s.split('').reverse().join('')
}
```

**解法2：双指针**
```javascript
function reverseString(s) {
  const arr = s.split('')
  let left = 0
  let right = arr.length - 1
  
  while (left < right) {
    [arr[left], arr[right]] = [arr[right], arr[left]]
    left++
    right--
  }
  
  return arr.join('')
}
```
时间复杂度：O(n)，空间复杂度：O(n)

### 2. 判断回文字符串

**题目：** 给定一个字符串，判断它是不是回文串。

**解法1：双指针**
```javascript
function isPalindrome(s) {
  // 先处理字符串，只保留字母和数字，转小写
  s = s.replace(/[^a-zA-Z0-9]/g, '').toLowerCase()
  
  let left = 0
  let right = s.length - 1
  
  while (left < right) {
    if (s[left] !== s[right]) {
      return false
    }
    left++
    right--
  }
  
  return true
}
```
时间复杂度：O(n)，空间复杂度：O(1)

**解法2：反转比较**
```javascript
function isPalindrome(s) {
  s = s.replace(/[^a-zA-Z0-9]/g, '').toLowerCase()
  return s === s.split('').reverse().join('')
}
```

### 3. 无重复字符的最长子串

**题目：** 给定一个字符串，找出不含有重复字符的最长子串的长度。

**解法：滑动窗口**
```javascript
function lengthOfLongestSubstring(s) {
  const map = new Map()
  let maxLen = 0
  let left = 0
  
  for (let right = 0; right < s.length; right++) {
    if (map.has(s[right]) && map.get(s[right]) >= left) {
      left = map.get(s[right]) + 1
    }
    map.set(s[right], right)
    maxLen = Math.max(maxLen, right - left + 1)
  }
  
  return maxLen
}
```
时间复杂度：O(n)，空间复杂度：O(min(m, n))，m 是字符集大小

### 4. 字符串相加

**题目：** 给定两个字符串形式的非负整数 num1 和 num2，返回它们的和。

**解法：模拟竖式加法**
```javascript
function addStrings(num1, num2) {
  let i = num1.length - 1
  let j = num2.length - 1
  let carry = 0
  let result = []
  
  while (i >= 0 || j >= 0 || carry > 0) {
    const x = i >= 0 ? Number(num1[i]) : 0
    const y = j >= 0 ? Number(num2[j]) : 0
    const sum = x + y + carry
    carry = Math.floor(sum / 10)
    result.push(sum % 10)
    i--
    j--
  }
  
  return result.reverse().join('')
}
```
时间复杂度：O(max(n,m))，空间复杂度：O(1)（不计返回结果）

## 四、链表

### 1. 链表结构

```javascript
class ListNode {
  constructor(val) {
    this.val = val
    this.next = null
  }
}
```

### 2. 反转链表

**题目：** 反转一个单链表。

**解法1：迭代**
```javascript
function reverseList(head) {
  let prev = null
  let curr = head
  
  while (curr) {
    const next = curr.next
    curr.next = prev
    prev = curr
    curr = next
  }
  
  return prev
}
```
时间复杂度：O(n)，空间复杂度：O(1)

**解法2：递归**
```javascript
function reverseList(head) {
  if (!head || !head.next) return head
  
  const newHead = reverseList(head.next)
  head.next.next = head
  head.next = null
  
  return newHead
}
```
时间复杂度：O(n)，空间复杂度：O(n)（递归栈）

### 3. 链表中环的检测

**题目：** 判断链表中是否有环。

**解法：快慢指针（Floyd 判圈算法）**
```javascript
function hasCycle(head) {
  if (!head || !head.next) return false
  
  let slow = head
  let fast = head.next
  
  while (slow !== fast) {
    if (!fast || !fast.next) return false
    slow = slow.next
    fast = fast.next.next
  }
  
  return true
}
```
时间复杂度：O(n)，空间复杂度：O(1)

**进阶：找到环的入口节点**
```javascript
function detectCycle(head) {
  if (!head || !head.next) return null
  
  let slow = head
  let fast = head
  
  while (fast && fast.next) {
    slow = slow.next
    fast = fast.next.next
    if (slow === fast) {
      // 找到相遇点后，一个从头开始，一个从相遇点开始，速度相同，相遇点就是入口
      slow = head
      while (slow !== fast) {
        slow = slow.next
        fast = fast.next
      }
      return slow
    }
  }
  
  return null
}
```

### 4. 合并两个有序链表

**题目：** 将两个升序链表合并为一个新的升序链表并返回。

**解法：递归**
```javascript
function mergeTwoLists(l1, l2) {
  if (!l1) return l2
  if (!l2) return l1
  
  if (l1.val < l2.val) {
    l1.next = mergeTwoLists(l1.next, l2)
    return l1
  } else {
    l2.next = mergeTwoLists(l1, l2.next)
    return l2
  }
}
```
时间复杂度：O(n+m)，空间复杂度：O(n+m)（递归栈）

**解法：迭代**
```javascript
function mergeTwoLists(l1, l2) {
  const dummy = new ListNode(0)
  let curr = dummy
  
  while (l1 && l2) {
    if (l1.val < l2.val) {
      curr.next = l1
      l1 = l1.next
    } else {
      curr.next = l2
      l2 = l2.next
    }
    curr = curr.next
  }
  
  curr.next = l1 || l2
  return dummy.next
}
```
时间复杂度：O(n+m)，空间复杂度：O(1)

### 5. 删除链表的倒数第 N 个节点

**题目：** 给你一个链表，删除链表的倒数第 n 个节点，并且返回链表的头结点。

**解法：快慢指针**
```javascript
function removeNthFromEnd(head, n) {
  const dummy = new ListNode(0)
  dummy.next = head
  
  let fast = dummy
  let slow = dummy
  
  // fast 先走 n 步
  for (let i = 0; i <= n; i++) {
    fast = fast.next
  }
  
  // 一起走，直到 fast 到末尾
  while (fast) {
    fast = fast.next
    slow = slow.next
  }
  
  // slow 的下一个就是要删除的节点
  slow.next = slow.next.next
  
  return dummy.next
}
```
时间复杂度：O(n)，空间复杂度：O(1)

## 五、栈与队列

### 1. 用栈实现队列

**题目：** 使用两个栈实现先入先出的队列。

```javascript
class MyQueue {
  constructor() {
    this.stack1 = []
    this.stack2 = []
  }
  
  push(x) {
    this.stack1.push(x)
  }
  
  pop() {
    if (this.stack2.length === 0) {
      while (this.stack1.length > 0) {
        this.stack2.push(this.stack1.pop())
      }
    }
    return this.stack2.pop()
  }
  
  peek() {
    if (this.stack2.length === 0) {
      while (this.stack1.length > 0) {
        this.stack2.push(this.stack1.pop())
      }
    }
    return this.stack2[this.stack2.length - 1]
  }
  
  empty() {
    return this.stack1.length === 0 && this.stack2.length === 0
  }
}
```

### 2. 用队列实现栈

**题目：** 使用队列实现栈的操作。

```javascript
class MyStack {
  constructor() {
    this.queue = []
  }
  
  push(x) {
    const size = this.queue.length
    this.queue.push(x)
    // 把前面的元素都移到后面
    for (let i = 0; i < size; i++) {
      this.queue.push(this.queue.shift())
    }
  }
  
  pop() {
    return this.queue.shift()
  }
  
  top() {
    return this.queue[0]
  }
  
  empty() {
    return this.queue.length === 0
  }
}
```

### 3. 有效的括号

**题目：** 给定一个只包括 '('、')'、'{'、'}'、'['、']' 的字符串，判断字符串是否有效。

**解法：栈**
```javascript
function isValid(s) {
  const stack = []
  const map = {
    '(': ')',
    '[': ']',
    '{': '}'
  }
  
  for (let i = 0; i < s.length; i++) {
    if (map[s[i]]) {
      // 左括号，入栈
      stack.push(s[i])
    } else {
      // 右括号，检查是否匹配
      if (stack.length === 0 || map[stack.pop()] !== s[i]) {
        return false
      }
    }
  }
  
  return stack.length === 0
}
```
时间复杂度：O(n)，空间复杂度：O(n)

## 六、树

### 1. 二叉树结构

```javascript
class TreeNode {
  constructor(val) {
    this.val = val
    this.left = null
    this.right = null
  }
}
```

### 2. 二叉树的遍历

**前序遍历（根-左-右）：**
```javascript
// 递归
function preorderTraversal(root) {
  const result = []
  function traverse(node) {
    if (!node) return
    result.push(node.val)
    traverse(node.left)
    traverse(node.right)
  }
  traverse(root)
  return result
}

// 迭代
function preorderTraversal(root) {
  if (!root) return []
  const result = []
  const stack = [root]
  
  while (stack.length > 0) {
    const node = stack.pop()
    result.push(node.val)
    if (node.right) stack.push(node.right)
    if (node.left) stack.push(node.left)
  }
  
  return result
}
```

**中序遍历（左-根-右）：**
```javascript
// 递归
function inorderTraversal(root) {
  const result = []
  function traverse(node) {
    if (!node) return
    traverse(node.left)
    result.push(node.val)
    traverse(node.right)
  }
  traverse(root)
  return result
}

// 迭代
function inorderTraversal(root) {
  if (!root) return []
  const result = []
  const stack = []
  let curr = root
  
  while (curr || stack.length > 0) {
    while (curr) {
      stack.push(curr)
      curr = curr.left
    }
    curr = stack.pop()
    result.push(curr.val)
    curr = curr.right
  }
  
  return result
}
```

**后序遍历（左-右-根）：**
```javascript
// 递归
function postorderTraversal(root) {
  const result = []
  function traverse(node) {
    if (!node) return
    traverse(node.left)
    traverse(node.right)
    result.push(node.val)
  }
  traverse(root)
  return result
}
```

**层序遍历（BFS）：**
```javascript
function levelOrder(root) {
  if (!root) return []
  const result = []
  const queue = [root]
  
  while (queue.length > 0) {
    const levelSize = queue.length
    const level = []
    
    for (let i = 0; i < levelSize; i++) {
      const node = queue.shift()
      level.push(node.val)
      if (node.left) queue.push(node.left)
      if (node.right) queue.push(node.right)
    }
    
    result.push(level)
  }
  
  return result
}
```

### 3. 二叉树的最大深度

**题目：** 给定一个二叉树，找出其最大深度。

**解法：递归**
```javascript
function maxDepth(root) {
  if (!root) return 0
  const leftDepth = maxDepth(root.left)
  const rightDepth = maxDepth(root.right)
  return Math.max(leftDepth, rightDepth) + 1
}
```
时间复杂度：O(n)，空间复杂度：O(h)，h 是树的高度

**解法：BFS**
```javascript
function maxDepth(root) {
  if (!root) return 0
  let depth = 0
  const queue = [root]
  
  while (queue.length > 0) {
    const levelSize = queue.length
    for (let i = 0; i < levelSize; i++) {
      const node = queue.shift()
      if (node.left) queue.push(node.left)
      if (node.right) queue.push(node.right)
    }
    depth++
  }
  
  return depth
}
```

### 4. 平衡二叉树

**题目：** 判断一棵二叉树是否是高度平衡的二叉树。

**解法：自顶向下（暴力法）**
```javascript
function isBalanced(root) {
  if (!root) return true
  
  function depth(node) {
    if (!node) return 0
    return Math.max(depth(node.left), depth(node.right)) + 1
  }
  
  const leftDepth = depth(root.left)
  const rightDepth = depth(root.right)
  
  return Math.abs(leftDepth - rightDepth) <= 1 
    && isBalanced(root.left) 
    && isBalanced(root.right)
}
```
时间复杂度：O(n²)

**解法：自底向上（后序遍历优化）**
```javascript
function isBalanced(root) {
  function getDepth(node) {
    if (!node) return 0
    const leftDepth = getDepth(node.left)
    if (leftDepth === -1) return -1 // 左子树不平衡
    const rightDepth = getDepth(node.right)
    if (rightDepth === -1) return -1 // 右子树不平衡
    if (Math.abs(leftDepth - rightDepth) > 1) return -1 // 当前节点不平衡
    return Math.max(leftDepth, rightDepth) + 1
  }
  
  return getDepth(root) !== -1
}
```
时间复杂度：O(n)

### 5. 对称二叉树

**题目：** 给定一个二叉树，检查它是否是镜像对称的。

**解法：递归**
```javascript
function isSymmetric(root) {
  if (!root) return true
  
  function isMirror(left, right) {
    if (!left && !right) return true
    if (!left || !right) return false
    return left.val === right.val 
      && isMirror(left.left, right.right) 
      && isMirror(left.right, right.left)
  }
  
  return isMirror(root.left, root.right)
}
```

## 七、排序算法

### 1. 冒泡排序

```javascript
function bubbleSort(arr) {
  const n = arr.length
  for (let i = 0; i < n - 1; i++) {
    let swapped = false
    for (let j = 0; j < n - i - 1; j++) {
      if (arr[j] > arr[j + 1]) {
        [arr[j], arr[j + 1]] = [arr[j + 1], arr[j]]
        swapped = true
      }
    }
    if (!swapped) break // 没有交换，已经有序
  }
  return arr
}
```
时间复杂度：O(n²)，空间复杂度：O(1)，稳定

### 2. 选择排序

```javascript
function selectionSort(arr) {
  const n = arr.length
  for (let i = 0; i < n - 1; i++) {
    let minIndex = i
    for (let j = i + 1; j < n; j++) {
      if (arr[j] < arr[minIndex]) {
        minIndex = j
      }
    }
    [arr[i], arr[minIndex]] = [arr[minIndex], arr[i]]
  }
  return arr
}
```
时间复杂度：O(n²)，空间复杂度：O(1)，不稳定

### 3. 插入排序

```javascript
function insertionSort(arr) {
  const n = arr.length
  for (let i = 1; i < n; i++) {
    const current = arr[i]
    let j = i - 1
    while (j >= 0 && arr[j] > current) {
      arr[j + 1] = arr[j]
      j--
    }
    arr[j + 1] = current
  }
  return arr
}
```
时间复杂度：O(n²)，空间复杂度：O(1)，稳定

### 4. 快速排序

```javascript
function quickSort(arr) {
  if (arr.length <= 1) return arr
  
  const pivotIndex = Math.floor(arr.length / 2)
  const pivot = arr[pivotIndex]
  const left = []
  const right = []
  
  for (let i = 0; i < arr.length; i++) {
    if (i === pivotIndex) continue
    if (arr[i] < pivot) {
      left.push(arr[i])
    } else {
      right.push(arr[i])
    }
  }
  
  return [...quickSort(left), pivot, ...quickSort(right)]
}
```
时间复杂度：平均 O(n log n)，最坏 O(n²)，空间复杂度：O(log n)，不稳定

### 5. 归并排序

```javascript
function mergeSort(arr) {
  if (arr.length <= 1) return arr
  
  const mid = Math.floor(arr.length / 2)
  const left = arr.slice(0, mid)
  const right = arr.slice(mid)
  
  function merge(left, right) {
    const result = []
    let i = 0
    let j = 0
    
    while (i < left.length && j < right.length) {
      if (left[i] <= right[j]) {
        result.push(left[i])
        i++
      } else {
        result.push(right[j])
        j++
      }
    }
    
    return result.concat(left.slice(i)).concat(right.slice(j))
  }
  
  return merge(mergeSort(left), mergeSort(right))
}
```
时间复杂度：O(n log n)，空间复杂度：O(n)，稳定

## 八、查找算法

### 1. 二分查找

**题目：** 在有序数组中查找目标值，返回其索引。

```javascript
function binarySearch(nums, target) {
  let left = 0
  let right = nums.length - 1
  
  while (left <= right) {
    const mid = Math.floor((left + right) / 2)
    if (nums[mid] === target) {
      return mid
    } else if (nums[mid] < target) {
      left = mid + 1
    } else {
      right = mid - 1
    }
  }
  
  return -1
}
```
时间复杂度：O(log n)，空间复杂度：O(1)

### 2. 二分查找变体

**查找第一个等于 target 的位置：**

function searchFirst(nums, target) {

## 九、动态规划

### 1. 爬楼梯

**题目：** 假设你正在爬楼梯。需要 n 阶你才能到达楼顶。每次你可以爬 1 或 2 个台阶。你有多少种不同的方法可以爬到楼顶呢？

**解法：动态规划**
```javascript
function climbStairs(n) {
  if (n <= 2) return n
  
  let dp1 = 1 // 第1阶
  let dp2 = 2 // 第2阶
  
  for (let i = 3; i <= n; i++) {
    const temp = dp1 + dp2
    dp1 = dp2
    dp2 = temp
  }
  
  return dp2
}
```
时间复杂度：O(n)，空间复杂度：O(1)

### 2. 斐波那契数列

function fib(n) {
  if (n <= 1) return n

  let dp1 = 1
  
  for (let i = 2; i <= n; i++) {

  }

### 3. 零钱兑换

**题目：** 给你一个整数数组 coins，表示不同面额的硬币；以及一个整数 amount，表示总金额。返回可以凑成总金额的最少硬币个数。

```javascript
function coinChange(coins, amount) {
  const dp = new Array(amount + 1).fill(Infinity)
  dp[0] = 0
  
  for (let i = 1; i <= amount; i++) {
    for (const coin of coins) {
      if (coin <= i) {
        dp[i] = Math.min(dp[i], dp[i - coin] + 1)
      }
    }
  }
  
  return dp[amount] === Infinity ? -1 : dp[amount]
}
```

## 十、算法解题思路总结

### 1. 数组问题常见思路

- **双指针**：有序数组、两数之和、移动零等
- **滑动窗口**：子串、子数组问题
- **哈希表**：去重、查找、统计
- **排序**：先排序再处理
- **二分查找**：有序数组查找

### 2. 链表问题常见思路

- **虚拟头节点**：处理头节点特殊情况
- **快慢指针**：环的检测、找中点、倒数第k个
- **多指针**：反转、合并、排序
- **递归**：反转、合并等

### 3. 树问题常见思路

- **递归**：大多数树的问题都可以用递归
- **BFS（层序遍历）**：层序相关、最短路径
- **DFS（前/中/后序遍历）**：深度相关、路径问题
- **迭代**：递归的迭代实现

### 4. 排序算法选择

- 数据量小：插入排序
- 数据量中等：希尔排序
- 数据量大：快速排序、归并排序、堆排序
- 需要稳定：归并排序
- 空间有限：堆排序

### 5. 面试算法题答题技巧

1. **先理解题目**：确认题目要求，有问题及时问
2. **说思路**：先讲整体思路，再写代码
3. **分析复杂度**：时间复杂度和空间复杂度
4. **考虑边界**：空值、特殊情况
5. **优化思路**：有没有更好的解法
6. **测试用例**：举例验证
