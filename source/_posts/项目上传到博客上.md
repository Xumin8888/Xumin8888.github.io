## 新增N个无后端项目到Hexo博客

### 一、核心前提

#### 1. Hexo博客可正常部署 2. 前端项目本地能正常运行（无后端依赖）

### 二、单个项目部署步骤（N个项目重复此流程）

#### 1. 前端准备

* 终端执行：npm run dev，确认本地页面正常（无报错）
* 配置（必做，避免解析失败）：
* 我给你一个**万能vite.config.js模板**（以后直接复制）

  |  |  |
  | --- | --- |
  | ``` 1 2 3 4 5 6 7 8 ``` | ``` import { defineConfig } from 'vite'      export default defineConfig({     base: '/demos/这里改成你的文件夹名/',     build: {       outDir: 'dist'     }   }) ``` |

  Vue项目：vue.config.js 添加 publicPath: ‘./‘

  React项目：package.json 添加 “homepage”: “./“

  原生JS：所有资源用相对路径（如./css/style.css）

#### 2. 前端打包

* Ctrl+C关闭本地服务，执行：npm run build
* 检查：生成dist文件夹，确保有index.html

#### 3. 博客建目录

* 进入Hexo博客 source/demos/，新建英文文件夹（如project-4）

#### 4. 复制文件

* 复制dist文件夹内所有内容，粘贴到新建的文件夹（不要复制dist本身）

#### 5. 部署博客

终端按顺序执行（Hexo根目录）：

hexo clean  
hexo g  
hexo d

#### 6. 访问验证

* 访问路径：[https://xumin8888.github.io/demos/项目文件夹名/（如project-4）](https://xumin8888.github.io/demos/%E9%A1%B9%E7%9B%AE%E6%96%87%E4%BB%B6%E5%A4%B9%E5%90%8D/%EF%BC%88%E5%A6%82project-4%EF%BC%89)
* 解析失败排查：① 确认有index.html ② 路径配置正确 ③ 重新执行部署命令

### 三、N个项目简化流程（重复用）

#### 1. npm run dev 检查前端 → 2. npm run build 打包 → 3. source/demos/新建英文目录 → 4. 复制dist内内容 → 5. hexo clean && hexo g && hexo d

### 四、关键注意事项（避坑）

#### 1. 目录名无中文、空格 2. 不复制整个dist文件夹 3. 必做前端路径配置 4. 解析失败优先重新部署
